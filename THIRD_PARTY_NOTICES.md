# Componentes de terceiros

Os fontes em `jcompany-runtime/src/main/java/org/jcompany` provêm de `jCompany-Community-1.2.zip`, disponibilizado com o desafio. Seus cabeçalhos declaram GNU GPL versão 3; foram preservados. O arquivo LICENSE contém essa licença. O código novo é disponibilizado sob GPL-3.0-only para manter uma distribuição coerente com os fontes incorporados.

Referências de origem:
- https://sourceforge.net/projects/jcompany/
- https://jcompany.sourceforge.net/
- https://softwarepublico.gov.br/social/jaguar

`jcompany-runtime/upstream-manifest.json` registra caminho e SHA-256 de cada arquivo original. Os arquivos foram convertidos de ISO-8859-1 para UTF-8. `docs/jcompany-compatibility.patch` registra as duas adaptações semânticas. O POM reconstruído é local e não é um lançamento oficial do jCompany. As dependências Maven mantêm suas licenças próprias.
